# 지원 가능한 양식 / 지원 불가능한 양식

새 양식을 만들기 전에 이 문서를 먼저 보면, "이 템플릿이 될까?" 를 미리 판단할 수
있습니다. 아래 표의 ✅ 항목은 모두 `tests/test_matrix.py` 로 **실제 파일을 만들어
돌려보고 결과를 다시 열어 확인한** 것들입니다.

---

## 1. 워드 템플릿 (.docx)

### 되는 것

| 구조 | 상태 | 검증 케이스 |
|---|---|---|
| 표 없이 본문 문장 사이에 `{{태그}}` | ✅ | W1 |
| 병합 없는 일반 표 | ✅ | W2 |
| 가로·세로 병합이 섞인 복잡한 표 (지출결의서형) | ✅ | W3 |
| 표가 여러 개 섞인 문서 (회의록형) | ✅ | W4 |
| 표 안의 표 (중첩 표) | ✅ | W3/W4 스캔 |
| 같은 태그가 문서 안에서 여러 번 반복 | ✅ | W5 |
| 머리글 / 바닥글의 태그 | ✅ | W6 |
| 첫 페이지·짝수 페이지 전용 머리글/바닥글 | ✅ | 스캔 지원 |
| 행 수가 유동적인 표 (`{%tr for %}` 반복) | ✅ | W7 |
| 한글·공백·괄호·하이픈이 든 태그 이름 (`{{연-월}}`) | ✅ | W8 |
| 텍스트 상자·도형 안의 태그 | ✅ | W9 |
| 워드가 태그를 여러 서식 조각으로 쪼개 놓은 경우 | ✅ | docxtpl `patch_xml` |
| 그림·차트·SmartArt 가 들어 있는 문서 | ✅ | 손대지 않고 그대로 보존 |

### 안 되는 것 / 주의할 것

| 구조 | 이유와 대처 |
|---|---|
| **구형 `.doc`** | 형식 자체가 다릅니다. 워드에서 `.docx` 로 다시 저장하세요. |
| **한글(HWP) 문서** | 지원하지 않습니다. `.docx` 로 변환 후 사용하세요. |
| **암호가 걸린 문서** | 열 수 없습니다. 암호를 푼 사본을 쓰세요. |
| **태그를 반쯤 지운 경우** (`{{사용량}`) | 짝이 안 맞으면 태그로 인식하지 않고 글자 그대로 남습니다. |
| **`{%tr for %}` 와 `{%tr endfor %}` 가 같은 행** | 표식이 든 행은 통째로 사라지므로 반복이 깨집니다. 각각 자기 행을 차지해야 합니다. |
| **`{{ 함수(인자) }}` 형태** | jinja2 식으로 취급되어 매핑 항목에 나오지 않습니다. 태그 이름에 `이름(` 형태를 붙이지 마세요. `{{사용량 (2026-01)}}` 처럼 **괄호 앞에 공백**을 두면 태그로 인식됩니다. |
| **`{{ r.항목 }}`, `{{ 값\|round(1) }}`** | 의도적으로 그대로 둡니다. 반복문 안에서 직접 쓰는 고급 문법용입니다. |
| **각주·미주 안의 태그** | 렌더링은 되지만 스캔 목록에는 나오지 않을 수 있습니다. |
| **자동 목차(TOC)** | 값은 채워지지만 목차 쪽수는 워드에서 `F9` 로 갱신해야 합니다. |

## 2. 엑셀 템플릿 (.xlsx / .xlsm)

### 되는 것

| 구조 | 상태 | 검증 케이스 |
|---|---|---|
| 단일 시트, 위아래로 연속된 라벨/값 | ✅ | X1 |
| 여러 시트에 나눠 값 채우기 | ✅ | X2 |
| 열·행을 건너뛰는 불규칙한 배치 | ✅ | X3 |
| 테두리·배경색·글꼴·가운데정렬 유지 | ✅ | X4 |
| 표시형식(`#,##0.0`) 유지 — 숫자가 숫자로 들어감 | ✅ | X4 |
| 셀 병합 유지 | ✅ | X4 |
| **수식 보존** (`=SUM(B2:B3)`, `=IF(...)`) | ✅ | X5 |
| 값을 채운 셀을 참조하는 수식이 정상 계산 | ✅ | X5 (열 때 자동 재계산) |
| `{{#표}}` 자리에 집계표 통째로 삽입 | ✅ | X6 |
| 태그 없이 셀 좌표(`요약!B3`)로 직접 지정 | ✅ | X7 |
| 셀 안에 글자와 태그가 섞인 경우 (`작성자: {{담당자}}`) | ✅ | X2 |
| 시트 이름에 공백이 있는 경우 (`'월간 요약'!B3`) | ✅ | 따옴표 표기 지원 |
| 틀 고정, 조건부 서식, 데이터 유효성 | ✅ | openpyxl 왕복 확인 |
| `.xlsm` 매크로 | ✅ | `keep_vba` 로 보존 |

### 안 되는 것 / 주의할 것

| 구조 | 이유와 대처 |
|---|---|
| **구형 `.xls`** | 엑셀에서 `.xlsx` 로 다시 저장하세요. |
| **차트·이미지·도형** | openpyxl 이 파일을 다시 쓰면서 **소실될 수 있습니다.** 로고나 차트가 들어간 양식은 생성 후 결과 파일을 반드시 눈으로 확인하세요. 소실된다면 차트는 결과 파일에 나중에 붙이거나, 워드 템플릿 쪽을 쓰는 편이 안전합니다. |
| **피벗 테이블** | 정의는 남지만 새로 고침이 필요할 수 있습니다. |
| **수식의 '계산된 값'** | openpyxl 은 계산 결과 캐시를 보존하지 못합니다. 그래서 파일을 열 때 자동 재계산되도록 표시해 둡니다. 엑셀 없이 결과 파일을 프로그램으로 읽으면 수식 셀이 비어 보일 수 있습니다. |
| **머리글/바닥글(페이지 설정)의 태그** | 셀이 아니라 인쇄 설정이라 치환되지 않습니다. |
| **도형·텍스트 상자 안의 태그** | 워드와 달리 엑셀에서는 치환되지 않습니다. 셀에 적어 주세요. |
| **병합된 셀의 좌상단이 아닌 칸에 값 지정** | 엑셀 구조상 불가능합니다. 자동으로 좌상단 칸에 씁니다. |
| **`{{#표}}` 아래에 기존 내용이 있는 경우** | 표가 그 위에 덮어씁니다. 앵커 아래에는 여유를 두세요. |

## 3. 원본 데이터 엑셀

### 되는 것

| 구조 | 상태 | 검증 케이스 |
|---|---|---|
| 헤더 1행 | ✅ | S1 |
| 헤더 2행 (상위 헤더 병합) → `상위 / 하위` 로 합침 | ✅ | S2 |
| 표가 시트 왼쪽 위에서 시작하지 않음 (제목 줄이 위에 있음) | ✅ | S3 |
| 빈 셀·빈 행이 섞임 | ✅ | S3 |
| 숫자·문자·날짜·`1,234` 형태 문자열 혼재 | ✅ | S4 |
| 데이터 행이 200행 이상 | ✅ | S11 |
| 데이터 행이 1행뿐 | ✅ | S12 |
| 셀 범위 직접 지정 (`B3:G40`) | ✅ | |
| 날짜가 열 방향으로 늘어선 표 → 전치 옵션 | ✅ | S10 / A7 |
| 컬럼 이름이 중복 → `이름`, `이름_1` 로 구분 | ✅ | |

### 안 되는 것 / 주의할 것

| 구조 | 이유와 대처 |
|---|---|
| **한 시트에 표가 여러 개 떨어져 있음** | 자동 감지가 전체를 한 표로 잡습니다. 셀 범위를 직접 지정하세요. |
| **헤더가 3행 이상** | 자동 감지는 2행까지만 추정합니다. 1단계에서 헤더 행 수를 직접 입력하세요. |
| **세로로 라벨-값이 반복되는 카드형 배치** | 표 형태가 아니면 읽지 못합니다. 전치 옵션으로 해결되는 경우가 있습니다. |
| **`.csv`** | 현재는 `.xlsx` / `.xlsm` 만 지원합니다. 엑셀에서 열어 저장하세요. |
| **셀에 수식만 있고 계산 결과가 저장되지 않은 파일** | 원본은 계산된 값을 읽으므로, 엑셀에서 한 번 열어 저장한 뒤 쓰세요. |

## 4. 일 → 월 집계

### 되는 것

| 상황 | 상태 | 검증 케이스 |
|---|---|---|
| 월 중간 날짜 누락 (28일치만 있음) | ✅ | W2 (28일 집계) |
| 여러 달 혼재 → 월별 보고서 각각 | ✅ | A1 (3개 파일) |
| 여러 달 혼재 → 한 보고서에 월별 나열 | ✅ | W7 / W8 / X6 |
| `2026-01-05` / `2026/01/05` / `2026.01.05` | ✅ | A2 |
| `20260105` / `2026년 1월 5일` | ✅ | A2 |
| 엑셀 일련번호 (`46059`) | ✅ | A2 |
| `01/05` (연도 없음) → 기준 연도로 보완 | ✅ | A2 |
| `5일` (연·월 없음) → 기준 연/월 입력 필요 | ✅ | A3 |
| `2026-01-05 09:30` (시간 포함) | ✅ | S4 |
| 주말 제외 | ✅ | A4 |
| 주말 + 공휴일 제외 | ✅ | A5 |
| 특정 월만 골라서 집계 | ✅ | A6 |
| 항목별로 다른 집계 방식 (합산/평균/최대/최소/건수/첫값/마지막값) | ✅ | 전 케이스 |
| `1,234` 같은 문자열 숫자 합산 | ✅ | S4 |
| 미리보기에서 값을 손으로 고쳐 반영 | ✅ | GUI 4단계 |

### 안 되는 것 / 주의할 것

| 상황 | 이유와 대처 |
|---|---|
| **숫자 컬럼이 날짜로 잘못 잡힘** | 컬럼 이름에 날짜 힌트(`일자`, `날짜`, `date` 등)가 없는 맨숫자 컬럼은 날짜 후보에서 제외합니다. 그래도 헷갈리면 4단계에서 날짜 컬럼을 직접 고르세요. |
| **`5일` 처럼 일자만 있는 표에서 기준 연/월 미입력** | 어느 달인지 알 수 없어 집계가 실패합니다. 기준 연/월을 반드시 입력하세요. |
| **주 단위·분기 단위 집계** | 현재는 월 단위만 지원합니다. |
| **공휴일 자동 인식** | 인터넷을 쓰지 않으므로 공휴일은 직접 입력해야 합니다. |
| **여러 달 나열 모드에서 달을 지정하지 않은 태그** | `{{사용량}}` 처럼 달이 없는 태그는 어느 달인지 알 수 없어 `3596 / 6006 / 3055` 처럼 전부 나열됩니다. 특정 달을 원하면 `{{사용량 (2026-01)}}` 로 쓰세요. |
| **1900-02-29 이전 날짜의 엑셀 일련번호** | 엑셀 자체의 윤년 버그 구간이라 하루 어긋날 수 있습니다. |

## 5. 오류가 났을 때

프로그램은 스택 트레이스 대신 사람이 읽는 메시지와 해결 방법을 보여 줍니다.

| 메시지 | 해결 |
|---|---|
| `'.txt' 형식은 읽을 수 없습니다` | `.xlsx` / `.xlsm` 파일을 고르세요. |
| `'○○' 시트가 없습니다` | 메시지에 나온 시트 목록에서 고르세요. |
| `셀 범위 'A1-Z9' 를 이해할 수 없습니다` | `B3:G40` 형식으로 입력하세요. |
| `날짜 컬럼을 찾지 못했습니다` | 4단계에서 날짜 컬럼을 직접 지정하거나 기준 연/월을 입력하세요. |
| `'○○' 에 연결된 컬럼이 원본에 없습니다` | 원본을 바꿨다면 3단계에서 매핑을 다시 지정하세요. |
| `결과 파일을 저장하지 못했습니다` | 같은 이름의 파일이 워드/엑셀에 열려 있으면 닫으세요. |
| `집계할 수 있는 날짜 데이터가 없습니다` | 주말/공휴일/대상월 제외 조건이 너무 강하지 않은지 확인하세요. |

## 6. 새 양식을 만들 때 권장 사항

1. 태그 이름은 **원본 엑셀의 컬럼 이름과 똑같이** 쓰면 자동 매칭이 붙습니다.
2. 엑셀 양식이라면 로고·차트는 되도록 넣지 말고, 필요하면 결과 파일에 나중에
   붙이세요.
3. 처음 쓰는 양식은 **작은 원본 데이터로 한 번 돌려보고 결과를 열어 확인**한 뒤
   실제 업무에 쓰세요.
4. 매핑을 저장해 두면 다음 달부터는 파일만 바꿔 끼우면 됩니다.
