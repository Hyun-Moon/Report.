# 사내 보고서 자동 생성기

엑셀 원본 데이터를 워드/엑셀 양식에 자동으로 채워 넣어 보고서를 만드는
**완전 로컬 실행** GUI 프로그램입니다. 인터넷 연결이 필요 없고, 어떤 데이터도
외부로 나가지 않습니다.

---

## 1. 빠른 시작

```bash
pip install -r requirements.txt      # 관리자 권한이 없으면 pip install --user ...
python app.py
```

창이 뜨면 맨 앞의 **⚡ 자동 완성** 탭에서 원본 엑셀 · 템플릿 · 저장 폴더
세 가지만 고르고 **[자동으로 완성]** 을 누르면 됩니다. 원본 워크북의
**모든 시트**를 훑어서(한 시트에 표가 여러 개 섞여 있어도 표 단위까지
쪼개서) 템플릿 태그와 이름이 맞는 표를 자동으로 찾아 연결하고 바로 보고서를
만듭니다. 한 번 성공하면 다음부터 재사용하도록 매핑을 `mappings/` 에 저장해
두므로, 같은 파일 조합은 그다음부터 훨씬 빨라집니다(저장된 매핑을 그대로
씁니다).

**엑셀 템플릿에 `{{태그}}` 가 하나도 없어도** (회사에서 쓰던 서식을 그대로
올린 경우 등) 자동 완성이 알아서 처리합니다 — "전력사용량" 처럼 라벨이 적힌
칸 바로 옆(오른쪽, 없으면 아래)의 빈 칸을 값 자리로 추론해서, 라벨 이름이
원본 컬럼 이름과 비슷하면 그대로 연결합니다. 어떤 라벨이 어떤 컬럼과
연결됐는지는 결과 화면에 전부 나오니(예: `전력사용량(kWh) → 전력`), 처음
한 번은 꼭 확인해 보세요 — 이름이 애매하게 겹치면 다른 컬럼과 잘못
연결될 수 있습니다. 잘못 연결된 게 있으면 3단계에서 고쳐서 다시 저장하면
다음부터는 고친 대로 재사용됩니다.

**그래도 자동 완성이 안 될 때** — 워드(.docx) 템플릿은 `{{태그}}` 가 꼭
있어야 합니다(라벨 추론은 엑셀 템플릿에서만 됩니다). 또는 원본의 어느
시트에도 태그(라벨)와 이름이 비슷한 표가 없으면 자동으로 완성할 수
없습니다. 이럴 땐 아래 1~3단계를 딱 한 번만 직접 거쳐 매핑을 저장해
주세요. 그 뒤로는 자동 완성 탭만 써도 됩니다.

**"파일 하나 = 하루치"인 원본이라면** (공조기/냉동기 운전일지처럼 매일 새
파일이 생기고, 그 안에 시간별 데이터 + 맨 아래 그날 요약값이 있는 경우)
**📁 여러 파일 취합** 탭을 먼저 씁니다. 그 달의 파일이 모인 폴더를 고르고,
표본 파일 하나를 미리보기로 확인해 "그날 요약값이 있는 행 번호"를 지정하면,
폴더 안의 파일을 전부 읽어 날짜순으로 한 줄씩 쌓은 월간표를 만들어
저장합니다. 그 결과 파일을 그대로 **[이 결과를 1단계 원본으로 사용]** 으로
넘기면, 그다음부터는(자동 완성이든 1~5단계든) 평소처럼 진행하면 됩니다.

세세하게 확인하거나 고치고 싶을 때도 1 → 5 탭을 순서대로 씁니다.

| 단계 | 하는 일 |
|---|---|
| 1. 원본 엑셀 | 데이터가 든 `.xlsx` 를 고르고 시트/범위를 정한 뒤 **[데이터 읽기]**. 한 시트에 표가 여러 개 섞여 있으면 **[표 후보 찾기…]** 로 원하는 표를 찾아 고를 수 있음 |
| 2. 템플릿 | 등록된 양식을 고르거나 새 양식을 올리고 **[템플릿 분석]** |
| 3. 매핑 | "엑셀 컬럼 ↔ 템플릿 태그" 연결을 확인·수정하고 **[매핑 저장]** |
| 4. 집계·미리보기 | 일단위 데이터를 월단위로 묶고, 값이 맞는지 확인(직접 수정 가능) |
| 5. 생성 | **[보고서 생성]** → `output/` 폴더에 결과 파일 저장 |

한 번 매핑을 저장해 두면 (자동 완성 탭이든, 1~3단계를 직접 거쳤든) 다음부터는
2단계에서 템플릿만 고르면 매핑이 자동으로 따라옵니다.

**태그 매핑을 매번 확인하기 귀찮으면**, 2단계의 **"이름으로 자동 매칭한 뒤,
매핑 확인 없이 바로 생성"** 체크박스를 켜세요. 템플릿 분석이 끝나자마자
(저장된 매핑이 있으면 그걸로, 없으면 이름이 비슷한 컬럼으로 자동 연결해서)
바로 5단계까지 진행해 보고서를 만듭니다. 처음 쓰는 템플릿이라면 태그 이름과
엑셀 컬럼 이름이 잘 안 맞을 수 있으니, 한 번은 3단계에서 결과를 확인해 보고
켜는 걸 권합니다.

### 배포용 exe 만들기

```bash
pip install pyinstaller
python build_exe.py            # dist/보고서생성기.exe
python build_exe.py --onedir   # 백신이 단일 exe 를 막을 때
```

## 2. 템플릿 만드는 법

### 워드 (.docx)

값이 들어갈 자리에 `{{태그명}}` 이라고 적으면 됩니다.

```
{{대상월}} 사용량은 {{사용량}} kWh 입니다.
```

- 본문, 표(병합·중첩 포함), 머리글/바닥글, 텍스트 상자 어디에 써도 됩니다.
- 같은 태그를 여러 번 써도 전부 같은 값으로 채워집니다.
- 태그 이름에 한글·공백·괄호·하이픈을 써도 됩니다 (`{{연-월}}`, `{{사용량 (2026-01)}}`).

행 수가 유동적인 표는 docxtpl 반복문을 씁니다. **`{%tr for %}` 와
`{%tr endfor %}` 는 각각 자기 행을 따로 차지해야 하고, 그 사이 행이 복제됩니다.**

| 연-월 | 일수 | 사용량 |
|---|---|---|
| `{%tr for r in rows %}` | | |
| `{{ r[0] }}` | `{{ r[1] }}` | `{{ r[2] }}` |
| `{%tr endfor %}` | | |

### 엑셀 (.xlsx)

두 가지 방법 중 편한 쪽을 쓰면 됩니다.

1. **셀에 태그 적기** — 값이 들어갈 셀에 `{{사용량}}` 이라고 써 둡니다.
   셀 위치가 바뀌어도 태그만 따라가므로 관리가 편합니다.
2. **셀 좌표 지정** — 양식을 손대지 않고, 3단계에서 **[엑셀 셀 좌표 추가…]** 로
   `요약!B3` 처럼 위치를 직접 지정합니다.

집계표를 통째로 써 넣으려면 시작 셀에 `{{#표}}` 라고 적습니다. 그 자리부터
아래로 헤더 + 데이터가 채워집니다.

테두리·배경색·글꼴·표시형식·병합·수식은 **그대로 보존**됩니다.

### 자동으로 채워지는 태그

따로 매핑하지 않아도 값이 들어가는 이름들입니다.

| 태그 | 값 |
|---|---|
| `{{오늘}}` | `2026-08-25` |
| `{{현재일시}}` / `{{생성일시}}` | `2026-08-25 14:03` |
| `{{대상월}}` | `2026년 1월` (집계 대상) |
| `{{연-월}}` | `2026-01` |
| `{{집계일수}}` | 집계에 들어간 날짜 수 |
| `{{원본파일}}` | 원본 엑셀 파일명 |
| `{{템플릿명}}` | 템플릿 파일명 |
| `{{작성자}}` | 윈도우 로그인 계정명 |

## 3. 일단위 → 월단위 집계

4단계에서 **[일단위 데이터를 월단위로 집계해서 사용]** 을 켜면 됩니다.

- **날짜 컬럼 자동 인식** — `2026-01-05`, `2026/01/05`, `20260105`,
  `2026년 1월 5일`, `01/05`, 엑셀 일련번호(`46027`) 를 모두 읽습니다.
- **항목별 집계 방식** — 사용량은 합산, 온도는 평균, 최대수요는 최댓값처럼
  컬럼마다 따로 정할 수 있습니다. 컬럼 이름을 보고 먼저 추천해 줍니다.
- **결측일 처리** — 28일치만 있어도 그대로 집계합니다. 평균은 값이 있는 날
  기준이고, 며칠이 들어갔는지는 `집계일수` 로 확인할 수 있습니다.
- **주말·공휴일 제외** — 체크 한 번, 공휴일은 `2026-01-01, 2026-03-01` 형식으로 입력.
- **여러 달이 섞여 있을 때** — 둘 중에 고릅니다.
  - `월별 보고서 각각` : 월마다 파일이 하나씩 (`양식_2026-01_20260825_140312.docx`)
  - `한 보고서에 월별로 나열` : `{{사용량 (2026-01)}}` 같은 태그나 `{{#표}}` 사용
- **미리보기에서 직접 수정** — 집계표의 값을 더블클릭해서 손으로 고칠 수 있고,
  고친 값이 그대로 보고서에 들어갑니다.

'1일, 2일 …' 처럼 일자만 있는 표는 **기준 연/월** 을 입력해 주면 됩니다.
날짜가 가로(열 방향)로 늘어선 표는 1단계에서 **[행/열 바꿔 읽기]** 를 켜세요.

## 4. 여러 파일(하루 1파일) 모아 월간표 만들기

공조기/냉동기/유량계 운전일지처럼 **매일 새 파일이 하나씩 생기고**, 그 안에
그날 시간별 데이터 + 맨 아래 그날 요약값(일사용량 등)이 들어 있는 경우입니다.
이런 원본은 한 파일 안에 날짜별 행이 쭉 있는 게 아니라서, 3장의 "일→월 집계"
가 아니라 **파일을 여러 개 모으는** 방식이 필요합니다. **📁 여러 파일 취합**
탭에서 합니다.

1. **폴더 선택** — 그 달의 파일들이 모인 폴더를 고릅니다.
2. **샘플 미리보기** — 시트 이름 · 셀 범위(예: `A3:C11`) · 헤더 행 수를
   지정하고 [샘플 미리보기] 를 누르면, 폴더의 첫 파일을 읽어 행 번호(`#`
   열, 0부터)와 함께 보여줍니다. 이때 인식된 날짜도 같이 나오니 파일명이나
   셀에서 날짜를 제대로 읽는지 확인할 수 있습니다.
3. **가져올 행 지정** — 미리보기에서 그날 요약값이 있는 행 번호를 적습니다
   (예: `6,7`). 요약값이 여러 행에 나뉘어 있으면(예: '일사용량 (TON)' 행과
   '일사용량 (N/M3)' 행이 따로) 행 이름표(예: `TON,N/M3`)를 같이 적어서
   컬럼 이름이 겹치지 않게 합니다. 가져올 컬럼을 비우면 그 행의 모든 컬럼을
   가져옵니다.
4. **[월간표 만들기]** — 폴더 안의 파일을 전부 읽어, 파일마다 지정한 행을
   뽑고 날짜순으로 한 줄씩 쌓아 `output/월간취합_○○.xlsx` 로 저장합니다.
   날짜를 못 찾았거나 지정한 행이 없는 파일은 조용히 빠지지 않고 결과
   화면에 파일명과 이유가 남습니다.
5. **[이 결과를 1단계 원본으로 사용]** — 만든 월간표 파일이 1단계 원본
   경로에 그대로 들어갑니다. 그다음부터는(⚡ 자동 완성이든 1~5단계든) 평소
   원본 엑셀 다루듯 이어서 쓰면 됩니다.

날짜는 **파일명 안의 `20260801`/`2026-08-01` 형태**를 먼저 찾고, 없으면
**파일을 열어 위쪽 셀에서 날짜로 읽히는 텍스트**(예: `2026년 8월 1일
토요일`)를 찾습니다. 시간 값처럼 작은 숫자를 날짜로 잘못 인식하지 않도록,
셀 안의 문자열은 4자리 연도가 들어 있을 때만 후보로 봅니다.

## 5. 폴더 구조

```
app.py                  진입점 (GUI / --cli)
build_exe.py            PyInstaller 빌드
run_tests.py            전체 검증 실행기
requirements.txt

reportgen/
  errors.py             사용자 친화 예외
  data_reader.py        원본 엑셀 읽기 (헤더 감지, 범위, 전치)
  dateutils.py          여러 형식의 날짜 파싱
  aggregator.py         일 → 월 집계
  mapping.py            컬럼 ↔ 태그 매핑, JSON 저장/로드
  generator.py          전체 흐름 오케스트레이션 (⚡ 자동 완성 포함)
  multifile.py          📁 하루 1파일 로그를 모아 월간표로 취합
  templating/
    base.py             공통 인터페이스
    word.py             docxtpl 기반 워드 처리
    excel.py            openpyxl 기반 엑셀 처리
    registry.py         templates/ 폴더 관리
  gui/
    app.py              자동 완성 · 여러 파일 취합 · 5단계 마법사
    widgets.py          공통 위젯

templates/              등록된 양식 (드롭다운에 표시)
mappings/               저장된 매핑 JSON
output/                 생성된 보고서
docs/SUPPORTED_FORMATS.md   지원/미지원 양식 정리
tests/                  검증 스크립트와 샘플 생성기
tools/                  기본 템플릿 생성기
```

각 계층은 아래 계층만 알기 때문에, 예를 들어 PDF 출력을 붙이고 싶다면
`templating/` 에 핸들러를 하나 더 추가하고 `open_template()` 에 등록하면 됩니다.

## 6. 명령줄 실행 (배치용)

원본/템플릿/저장 폴더만 지정하면 됩니다. 저장된 매핑이 있으면 그걸 쓰고,
없으면 GUI 의 ⚡ 자동 완성 탭과 똑같이 모든 시트를 훑어 자동으로 연결한 뒤
매핑을 새로 저장합니다.

```bash
python app.py --cli --source 1월실적.xlsx --template templates/기본_실적요약표.xlsx
```

`--mapping` 으로 매핑 파일 경로를 직접 지정할 수도 있고, `--out` 으로 저장
폴더를 바꿀 수도 있습니다. 템플릿에 태그가 하나도 없거나 어느 시트에서도
맞는 표를 찾지 못하면 오류 메시지로 원인을 알려 주고 종료합니다(이 경우는
GUI 로 한 번 매핑을 만들어 저장해야 합니다).

## 7. 검증

```bash
python run_tests.py            # 샘플 생성 + 양식 커버리지 + 예외 처리
python run_tests.py --gui      # GUI 스모크 테스트까지 (화면 필요)
```

`tests/make_fixtures.py` 가 워드 템플릿 12종, 엑셀 템플릿 9종, 원본 데이터 20종을
만들고, `tests/test_matrix.py` 가 40개 조합을 실제로 생성한 뒤 **결과 파일을 다시
열어** 값이 올바른 위치에 들어갔는지 확인합니다.

별도로 `tests/make_energy_fixtures.py` / `tests/test_energy_matrix.py` 는 에너지

## 8. 외부 통신을 하지 않는다는 것
